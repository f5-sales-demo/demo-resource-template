## Quick Start

<Steps>

1. Clone the repository

   <div data-xcsh-context="shell" data-xcsh-fields="XCSH_REPO_NAME">

   ```bash
   git clone https://github.com/f5-sales-demo/<XCSH_REPO_NAME>.git
   cd <XCSH_REPO_NAME>/terraform
   ```

   </div>

2. Copy the example variables file

   ```bash
   cp terraform.tfvars.example terraform.tfvars
   ```

3. Edit `terraform.tfvars` with your values

   <div data-xcsh-context="hcl">

   ```hcl
   subscription_id = "<XCSH_AZURE_SUBSCRIPTION_ID>"
   # TODO: Add component-specific required variables
   ```

   </div>

4. Initialize and plan

   ```bash
   terraform init
   terraform plan
   ```

5. Apply

   ```bash
   terraform apply
   ```

</Steps>
